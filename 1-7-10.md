# Essentials
| Name | Description | Notes |
| --- | :----------: | :---: |
| [lwjgl3ify](https://github.com/GTNewHorizons/lwjgl3ify/) | Allows using LWJGL3, which in turn allows to use Java 25 with many performance improvements | Some rare mods may not be compatible. See if [GTNH](https://github.com/orgs/GTNewHorizons/repositories) have updated forks |
| [UniMixins](https://modrinth.com/mod/unimixins) | Every mixin mod you need in a single batch | Replaces other mixin mods |
| [Angelica](https://modrinth.com/mod/angelica) | Backport of Sodium, Iris and many Sodium addons with rendering optimization features from several other optimization mods | [Replaces OptiFine](https://github.com/TheUsefulLists/UsefulMods/blob/main/Performance/Note%20on%20OptiFine.md) and most other optimization mods; some mods require a [GTNH](https://github.com/orgs/GTNewHorizons/repositories) fork to utilitize Angelica's features and to work, see the project's readme |
| [ArchaicFix](https://modrinth.com/mod/archaicfix) | A massive bugfix and optimization project |
| [Hodgepodge](https://modrinth.com/mod/hodgepodge) | A bugfix project with lots of customizable fixes and tweaks for vanilla and other mods |
| [BugTorch](https://modrinth.com/mod/bugtorch) | A bugfix project with backports of some QoL from newer Minecraft versions |
| [Healer](https://modrinth.com/mod/healer) | Fixes CVE-2021-44228 (also known as Log4Shell) vulnerability |
| [FoamFix](https://modrinth.com/mod/foamfix) | Optimizes the RAM usage and improves TPS stability |
| [Pathfinder Tweaks](https://github.com/HostileNetworks/OBSOLETE-ReignModpack/blob/master/mods/PathfinderTweaks-1.7.10-1.0.13.jar) | Fixes some issues with vanilla pathfinding |
| [ASM Fixes](https://www.curseforge.com/minecraft/mc-mods/asm-fixes-j-a-f-m) | Fixes a client crash |
| [Biome Decoration Fix](https://www.curseforge.com/minecraft/mc-mods/biome-decoration-fix) | Fixes the "Already decorating" crashes |
| [Careful Cast Corrector](https://www.curseforge.com/minecraft/mc-mods/careful-cast-corrector-ccc) | Fixes an extremely rare case of crashing during worldgen |
| [Squidless](https://www.curseforge.com/minecraft/mc-mods/squidless) | Reduced squid spawns to prevent lag |
| [AI Improvements](https://modrinth.com/mod/ai-improvements) | Optimizes the AI behaviour |
| [Fullscreen Windowed (Borderless)](https://www.curseforge.com/minecraft/mc-mods/fullscreen-windowed-borderless-for-minecraft) | Allows the use of Borderless Fullscreen in older versions | A bit clunky to activate. Allows to easily alt tab in and out of the game. |

# Mods not to use
| Name | Reasoning |
| --- | :--------: |
| OptiFine | [Breaks mods](https://github.com/TheUsefulLists/UsefulMods/blob/main/Performance/Note%20on%20OptiFine.md); permamently incompatible with Angelica |
| SpongeMixins and all the other Mixin mods | Superseded by [UniMixins](https://modrinth.com/mod/unimixins) |
| FalseTweaks | Not compatible with Angelica |
| RPLE | Not compatible with Angelica |
| FastCraft | Breaks mods and makes it very hard for other modders to work with it; permamently incompatible with Angelica |
| BetterFPS | Breaks mods; permamently incompatible with Angelica |
| OptimizationsAndTweaks | Permamently incompatible with Angelica |
| SmoothFont | May break text rendering in some mods; features implemented by Angelica |
| Neodymium | You *can* use it, but it has features that conflict with Angelica's |
| TexFix | Superseded by FoamFix |
| ESSENTIAL | Collects sensitive user data in background; super intrusive with a lot of FOMO and microtransactions. Use [e4mc Retro](https://www.curseforge.com/minecraft/mc-mods/e4mc-retro) instead |
