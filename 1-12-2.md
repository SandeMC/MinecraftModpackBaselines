# Essentials
| Name | Description | Notes |
| --- | :----------: | :---: |
| [Cleanroom](https://cleanroommc.com/wiki/end-user-guide/introduction) | An updated and maintained fork of Forge. Allows using LWJGL3, which in turn allows to use Java 25 with many performance improvements | Despite how it sounds, it maintains high compatibility with the vast majority of Forge mods |
| [MixinBooter](https://www.curseforge.com/minecraft/mc-mods/mixin-booter) | Required for mods listed below | Replaces other Mixin mods |
| [Celeritas](https://git.taumc.org/embeddedt/celeritas) | A fork of Embeddium and Oculus 1.7. **Incompatible with Nothirium, pick one or the other** | [Replaces OptiFine](https://github.com/TheUsefulLists/UsefulMods/blob/main/Performance/Note%20on%20OptiFine.md). Does not support shaders and does not include most addons you can see in Embeddium - but that's the best you're gonna get. Unofficial automatic builds can be found [here](https://github.com/kappa-maintainer/Celeritas-auto-build) |
| [Nothirium](https://www.curseforge.com/minecraft/mc-mods/nothirium) | An optimization mod similar to Sodium in spirit, but not a port of it. **Incompatible with Celeritas, pick one or the other** | [Replaces OptiFine](https://github.com/TheUsefulLists/UsefulMods/blob/main/Performance/Note%20on%20OptiFine.md). Also install [Naughtirium](https://www.curseforge.com/minecraft/mc-mods/naughthirium) for compatibility with other mods, such as LoliASM |
| [LoliASM](https://www.curseforge.com/minecraft/mc-mods/lolasm) | Heavily optimizes RAM usage and fixes crashes | Forks such as NormalASM or FermiumASM do not do anything meaningful; replaces FastFurnace |
| [Alfheim](https://modrinth.com/mod/alfheim-lighting-engine) | A distant fork of Phosphor, which improves the lighting engine performance | Replaces Hesperus |
| [Universal Tweaks](https://www.curseforge.com/minecraft/mc-mods/universal-tweaks) | A massive bugfix and tweaks project | Replaces AttributeFix, DupeFix Project, MUP, NetherPortalFix, RandomPatches, BetterFoliage, FastWorkbench, Surge |
| [Fixeroo](https://www.curseforge.com/minecraft/mc-mods/xp-orb-clump) | Fixes several bugs, adds a few small features | Replaces Clumps |
| [Bed Patch](https://www.curseforge.com/minecraft/mc-mods/bed-patch) | Fixes the stuck in bed bug |
| [ContainerFix](https://www.curseforge.com/minecraft/mc-mods/containerfix) | Properly closes the container UI when a container is broken |
| [Client Tweaks](https://modrinth.com/mod/client-tweaks) | Allows configuring many annoying behaviours from vanilla |

# Mods not to use
| Name | Reasoning |
| --- | :--------: |
| OptiFine | [Breaks mods](https://github.com/TheUsefulLists/UsefulMods/blob/main/Performance/Note%20on%20OptiFine.md); permamently incompatible with Angelica |
| ESSENTIAL | Collects sensitive user data in background; super intrusive with a lot of FOMO and microtransactions. Use [e4mc Retro](https://www.curseforge.com/minecraft/mc-mods/e4mc-retro) instead |
